Wirksam erst nach dem Commit. Der Alarm richtet sich nach der config.json im Repo — hier geänderte Werte gelten erst, wenn du die Datei dort ersetzt hast. Diese Seite kann nichts ins Repo schreiben.

Mail

Beliebige Adresse, kein Passwort nötig. Verschickt wird über ein festes Bot-Konto. Bei GitHub Actions gewinnt das Secret MAIL_TO über dieses Feld.
